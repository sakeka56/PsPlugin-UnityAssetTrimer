# Unity Asset Trim v1.0.0

Batch-trim transparent borders in Photoshop and export compact PNG assets for Unity.

## English

- Select multiple images or recursively process a folder.
- Keep even dimensions, add transparent padding and filter faint alpha noise.
- Preserve source documents, avoid output overwrites and save TSV batch logs.
- English and Simplified Chinese interfaces.
- Offline Windows setup EXE with Photoshop detection, backup, update and uninstall.

**Install:** download `UnityAssetTrim-Setup-1.0.0.exe`, choose Photoshop, and click **Install / Update**. Restart Photoshop, then open **File → Scripts → Unity Asset Trim**.

For manual installation, extract `UnityAssetTrim-Portable-1.0.0.zip` and run `Unity Asset Trim.jsx` through **File → Scripts → Browse**.

Tested with Photoshop 2024 / 25.2.0 on Windows. The installer is unsigned; checksum verification is available in `SHA256SUMS.txt`.
